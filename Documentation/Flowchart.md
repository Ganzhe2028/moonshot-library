# Flow Chart

## User Flow

登录

- 普通用户

  - 搜索

    - 展示结果书籍列表（列表包含基础信息）

      - 选中某本书

        - 展示基础信息

          - 评分、评论

          - 收藏

          - 借阅：isAvailable

            - T

              - 预约借阅

              - 立即借阅

            - F

              - 被借阅了

                - 预约借阅

              - 特殊情况，暂时不可借阅

  - 我的借阅

    - 用户信用状态

    - 借阅中书籍

    - 预约等待中书籍

    - 历史借阅

    - 收藏书籍

  - 建议增加书籍

  - Feedback 通道（一个按钮，点击链接飞书表单）

- 管理级别身份

  - 图书管理员

    - 增删改查

      - 增加

        - 录入书籍

      - 删除

        - 删除书籍

      - 修改

        - 修改基础信息

        - 特殊状态：暂时不可借阅

      - 查找

        - 用户

          - 用户信用状态

        - 书籍

          - 借阅历史

          - 状态

  - 开发 Dev.
    - 增删改查
